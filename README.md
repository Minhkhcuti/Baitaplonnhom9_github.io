# 💄 Cosmetic Shop Website

Website bán mỹ phẩm hiện đại được xây dựng phục vụ bài tập lớn môn Thiết Kế Web.

Dự án mô phỏng một website thương mại điện tử chuyên bán mỹ phẩm với giao diện hiện đại, responsive và các chức năng mua sắm cơ bản bằng Frontend.

---

# 📌 Giới Thiệu Đề Tài

Cosmetic Shop là website bán mỹ phẩm trực tuyến được phát triển bằng:

- HTML5
- CSS3
- Bootstrap 4
- JavaScript
- jQuery
- LocalStorage

Website tập trung vào:
- thiết kế giao diện hiện đại
- responsive design
- DOM manipulation
- xử lý dữ liệu phía Frontend
- làm việc nhóm bằng GitHub
